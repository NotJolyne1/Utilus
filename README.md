A utility mod for Among Us 3D that makes mods actually get along.

Most mod problems in this game come from mods stepping on each other. You click a menu and it clicks the game behind it. You type in a text box and the game invokes a keybind. A window drifts off screen when the map loads and you never see it again. Utilus quietly fixes all of that in the background so your mods just work, whether you run none, one, or a lot of them.

## What you get

Browse modded lobbies from a real in game list and join them in one click, or host and quick match your own modded gamemodes.

Menus that work together. Clicks stay on the window you clicked, typing stays in the box you are typing in, and a menu that gets thrown off screen when the scene changes snaps right back.

One button to hide everything. Press F1 or backslash to clear every mod GUI off your screen when you just want to look at the game, then press it again to bring them all back.

A quiet log. Utilus folds away the spam the game and other mods dump into your console so you can actually read it.

Updates on its own. When a new version drops, Utilus grabs it and restarts the game for you.

## Install

1. Install MelonLoader for Among Us 3D.
2. Drop Utilus.dll into your Among Us 3D Mods folder.
3. Launch the game.
